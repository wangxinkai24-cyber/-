# 奥地利大饭店 · 联机网页版（2–4 人）

朋友们在各自的手机或电脑上打开同一个网址，输入房间号就能一起玩。不需要注册账号。

## 一、本地先试玩（可选）

需要电脑上装有 Node.js 18 或更高版本（https://nodejs.org 下载 LTS 版）。

```bash
cd grandhotel
npm install
npm start
```

浏览器打开 http://localhost:3000 。同一台电脑可以开两个浏览器窗口（或一个普通窗口、一个无痕窗口）模拟两名玩家。
同一 Wi-Fi 下的手机，可以用电脑的局域网 IP 访问，例如 `http://192.168.1.23:3000`。

## 二、免费部署到网上（Render，推荐）

整个过程大约 10 分钟，只需要网页操作，不需要会写代码。

1. **注册 GitHub**：打开 https://github.com 注册账号（已有可跳过）。
2. **新建仓库**：右上角 “+” → “New repository”，名字随意（例如 `grandhotel`），选 Public 或 Private 都可以，点击 “Create repository”。
3. **上传代码**：在新仓库页面点 “uploading an existing file”，把解压后 `grandhotel` 文件夹里的**全部内容**（`server`、`public`、`package.json`、`package-lock.json`、`render.yaml`、`README.md`，不要上传 `node_modules`）拖进去，点击 “Commit changes”。
4. **注册 Render**：打开 https://render.com ，用 GitHub 账号登录。
5. **创建服务**：点击 “New +” → “Web Service” → 选择刚才的仓库，按下面填写：
   - Runtime：`Node`
   - Build Command：`npm install`
   - Start Command：`npm start`
   - Instance Type：`Free`
6. 点击 “Create Web Service”，等待 2–3 分钟显示 “Live”。页面顶部的网址（类似 `https://grandhotel-xxxx.onrender.com`）就是游戏地址，发给朋友即可。

> 也可以在 Render 选 “New +” → “Blueprint”，选择仓库，它会自动读取 `render.yaml` 完成配置。

### 免费版的注意事项
- 15 分钟没人访问时服务器会休眠，下次打开需要等约 30–60 秒唤醒。开局前先打开网页即可。
- 房间和对局保存在服务器内存中。**服务器休眠或重启后，进行中的对局会丢失**。一局游戏（约 60–90 分钟）中只要有人在线，就不会休眠。
- 其他平台（Railway、Fly.io、自己的 VPS）同样可用：任何能运行 `npm start` 并支持 WebSocket 的地方都可以。服务器读取环境变量 `PORT`。

## 三、怎么玩

1. 一人点 “创建房间”，把 4 位房间号发给朋友；其他人输入名字和房间号点 “加入房间”。
2. 房主选择酒店版图（月亮面/太阳面）和员工卡变体，点击 “开始游戏”。
3. 准备阶段：按顺序每人免费选 1 位起始宾客，然后各自准备最多 3 间客房（从左下角开始）。
4. 游戏中，页面最上方的金色提示栏会告诉你现在能做什么：
   - 点宾客牌 → 拿取宾客（付牌下方的费用）
   - 点行动格 → 拿骰子执行行动（勾选 “付1克朗，骰子数量+1” 可加强）
   - 点厨房里的餐点 → 再点需要它的宾客 → “确认上菜”（付1克朗，最多3个）
   - 点带 “✓ 可入住” 的宾客 → 再点闪烁的空闲客房 → 入住并获得奖励
   - 政务卡满足条件时会出现绿框，点击领取
   - 已雇用的 “每轮一次” 员工可以点击使用
   - 完成后点 “结束回合”
5. 掉线或关掉网页没关系：重新打开同一网址会自动回到原来的座位。
6. 点击玩家列表或酒店上方的名字，可以查看其他玩家的酒店。

## 四、实现说明

- 规则按随附中文规则书实现：7 轮、第 3/5/7 轮皇室计分、回合顺位板块、跳过与重投、额外行动、入住与区域奖励、政务卡、终局计分。
- 卡牌数据在 `server/data.js`，全部从实物照片录入：48 张员工卡、58 张宾客卡、12 张政务卡、12 块皇室板块、月亮面与 A/B/C/D 太阳面酒店版图。如发现某张卡的数据和实物不符，直接改这个文件即可。
- 以下几张宾客卡的图标我是按最合理的理解录入的，如有出入请改 `data.js`：
  - 特斯卡特利波卡（绿）：抽 3 张员工
  - 画家 / 建筑师（黄）：准备 2 间客房，每间减 1 克朗
  - 伯爵（蓝）：打出 2 次员工，每次减 1 克朗；女伯爵（蓝）：打出员工减 1 + 准备客房减 1
  - 医学顾问（红）：+3 克朗并免费拿取 1 位宾客
- 规则书没写明的细节：资金上限 20（资金记录条到 20 为止）；只剩【6】骰子而付不起 1 克朗时，仍须拿骰子但放弃行动；专家变体（轮抽员工）暂未实现，可选 “标准：随机发 6 张”。
- `npm test` 会让随机机器人自动对战 100 局，用来检查规则引擎不会卡死。
